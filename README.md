# Mandelbrot Set in C
Mandlebrot Set written in C and Raylib.

## Running the code
First, initialise the build system
```bash
cc -o nob nob.c
```
then, call the binary with the "run" argument to run the code.
```bash
./nob run
```

## Controls
W - Move up
A - Move left
S - Move down
D - Move right
Q - Zoom out
E - Zoom in
